# Verificação local

A aplicação normal abre em ../index.html. Esta pasta não é necessária para publicar a aplicação.

light-brightness-fixture.html é a fixture atual com conta/IDs fictícios e interceção de todas as chamadas. Abrir apenas em localhost. Permite ?room=studio, master ou living. Não substituir as associações fictícias por dispositivos reais. Os ficheiros *-fixture-header.txt são fontes pequenas para reconstruir cenários isolados; os scripts build-*.cjs geram pré-visualizações a partir dos módulos atuais, usando caminhos relativos à sua própria localização.

As capturas e páginas completas de versões anteriores foram retiradas na1.132. As referências a review/ nos registos históricos documentam o trabalho dessas versões; podem ser recuperadas no Git antes desta limpeza. A captura intensidade-bulb-1.131.png é o exemplo visual recente mantido.
